Speed

Everything that runs per game is C: the engine, the GA genome, the tree search and the network's forward pass (no Python inside a game). Python only hands out games to 7 worker processes and trains the network in numpy. The machine: a laptop with an 8-thread Intel i5-8250U (4 cores), 8 GB RAM, no GPU.

Why it's fast enough

  • The engine is a plain C struct (~20 KB per game), so a simulation copies the whole game with one assignment and abandons it with a longjmp when it reaches a new leaf: nothing to allocate or free.
  • The search only branches on buys (about 22 per player per game); everything in between is played straight through by the genome.
  • The network is 43,555 weights, about 44,000 multiply-adds per call, compiled with -O3 -march=native.
  • The first measurements without load: 9 µs per simulation with the net's value at the leaf; the GA rollout at leaves makes a simulation 2–3× dearer but was worth it (see the Log's bake-off rows).
