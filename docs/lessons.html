Lessons

What this project taught so far, newest first. Each lesson comes with the measurement behind it.

From this project

  • An honest judge is necessary, not sufficient. A fresh value head trained on the search's root value cut the held-out error from 1.24 to 0.70, but training with it did not lift the plateau: r3 (half-rollout leaves) 68.0% / 67.4% at iterations 10 / 20; r4 (value-only leaves, AlphaZero's setting) 66.8% / 67.7% / 66.6% at 10 / 20 / 30. With half of every leaf value coming from a GA rollout, the search learns to buy well for a game the GA finishes, which is a ceiling that training can't move. Value-only leaves remove that ceiling, but 30 iterations showed no gain.
  • Know when to stop. About 20 variants after the plateau began (simulations, cpuct, prior softening, net-buy rollouts, value targets, leaf mixes) all landed between 66% and 70% on the same 1,000 fresh games, ±3%. When every lever moves the result by less than the measurement's noise, more runs of the same method are not progress. The next step would be a different method, such as searching the action decisions too, not more of this one.
  • Read a fixed evaluation set with care. r4's per-iteration evaluation against the three bots rose to 80% (r2: 77%), but the same bots on the goal checks' fresh kingdoms gave 75.6% vs 75.3%. The evaluation reuses the same 600 bot games every iteration, so a gain there can be a fit to those kingdoms.
  • A training loss can improve while the model gets worse. r2's log showed the value error falling from 0.65 to 0.19. On 600 fresh games the same value head scored 0.68 (warm start), 0.92 (iteration 100) and 1.17 (iteration 357), worse than always predicting a draw (0.97). Each buy decision is trained on ~10 times, and the ~35 decisions of a game share one result, so the head memorised the games. Always keep one number measured on data the model never trained on; the trainer now logs value_mse_fresh, the error on each iteration's new games before training on them.
  • When the net agrees with the search, self-play stops teaching. From iteration ~100 to 357 the goal checks stayed at 69–70% while the net predicted the searched buy 97–98% of the time. The search then adds little: net 357 alone 66.7%, with 100 / 400 / 1,600 simulations 67.3% / 70.2% / 69.5% (1,000 games each, ±3%). At the warm start the search added 7 points over the net.
  • More exploration needs a trustworthy judge. Softening the net's prior inside the search (temperature 2, 4) changed nothing (68.6%, 69.1%); mixing in 25% uniform dropped the score to 48%. If the search is told to try every buy and its leaf values are noisy, some bad buy looks best by luck and the search picks it, the same winner's curse as picking the best of many evaluations. The ceiling is the leaf evaluation, not the exploration.
  • Visit shares are a bad policy target when the options are nearly equal. Run r1 trained on AlphaZero's standard target. Dominion buys are usually within a few percent of each other, so the visits mostly echo the net's prior plus the root's Dirichlet noise. One iteration later the net alone had dropped from 51.7% to 24.3% against the GA base. Run r2 trains on the search's chosen buy instead (expert iteration), without root noise.
  • A weak value net makes more search worse, not better. With the warm-started net's value alone at the leaves, the search scored 51% → 53% → 48% against the GA base at 100 → 400 → 1,600 simulations: the more it searched, the more it chased the value net's noise. Half value net, half GA rollout scored 52% → 58% → 60%. (400–600 games each, ±4–5%.)
  • Self-play from a weak net collapses fast. In a smoke test (net warm-started on only 600 games, 50 simulations), one iteration of training on its own search's choices took it from 62% to 0% against the bots: the search, guided by a near-random net, recommended buying Curses and passing, and the net learned exactly that. A good warm start and enough simulations come first.
  • Imitation is easy, prediction is hard. The net copies the GA's buys 98% of the time after 8 epochs, but its prediction of the winner stays at a mean squared error of 0.60 (1.0 = no idea): Dominion between two similar players stays close to a coin flip until late.
  • Check the plumbing against the old code. A test plays 20 games with GA seats through the new C agent and through dominion-v1's own ga_play_one: same scores, winners and turns. So "GA base" here is exactly the evolved genome, not a re-implementation.
